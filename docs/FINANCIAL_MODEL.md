# HOPPY FP：住宅ローン・教育資金の計算仕様（r58）

この文書は実装の意味を固定するための仕様です。表示額は家計シミュレーションであり、銀行審査で借りられる額ではありません。数値は内部では**万円**、画面では**円**に変換します。

## 1. 住宅ローンの月返済目安

基準年の通常の**夫婦の給与手取り**を起点に次を引きます。

- 生活費、食費、光熱費、保険、車関係費、子育て支出、年払い支出の月割り
- 当年の学校費（目標方式の教育資金からの充当分は差し引く）
- NISA・その他投資積立および現金貯蓄目標
- 予備費として入力した月額
- 固定資産税・修繕など毎月の住宅維持費

残りを「積立を維持する月返済目安」とします。マイナスのときだけ表示用に0円へ丸め、元の不足額は別に残します。

**出産予定年が購入年と同じ場合**は、その年だけの妻の収入減を返済全期間の給与水準とみなさないよう、翌年の通常時短収入を月返済の基準に使用します。ただし出産年の収入減・出産費用は年別キャッシュフローに残します。

ボーナス・給付金・一時収入は、毎月の返済原資には組み込まず、年別の資金繰り側に反映します。月給の25％などの機械的な上限は設けません。

## 2. ローン返済額から借入参考額への換算

- 月利 `r = 年利(%) / 1200`
- 返済月数 `n = 年数 × 12`
- 月返済額 `M` から借入額 `P = M × (1 − (1 + r)^(-n)) / r`（金利0％は `P = M × n`）

頭金0円・元利均等・毎月返済・金利一定が前提です。土地建物の価格から7％の購入諸費用を**別途現金支出**として予測します。必要な諸費用は契約条件で変動するため7％は仮定です。

「生活費だけを確保しNISA・現金貯蓄を見直す場合の上限」は別枠の**参考値**とし、推奨借入額とはしません。返済額や借入額はプラスの収支ではないため「＋」を付けません。収支の増減だけ符号を使います。

## 3. 年別資金繰りと家計診断

- 年別現金残高 = 前年末現金 + 年間手取り収入 + 賞与・給付金・イベント収入 − 年間支出 − NISA等への投資移管
- 住宅購入前は現在の家賃、購入月から住宅ローン＋維持費に切替。家賃との二重計上を避けます。
- 教育費が重い年に単年で赤字があっても、購入時の月返済を自動的にゼロにはしません。その代わり年次収支、現金残高、リスクを表示します。
- 購入時の生活防衛資金は「現在の現金−購入費」ではなく、**結婚式・旅行・給与・支出等を含む購入月末の予測現金**と比較します。年払い費用の発生月未登録分は月割りの概算です。
- 6か月分の生活費等はアプリ独自の確認目安で、審査条件ではありません。
- 手取りに対する住宅費の割合と、銀行審査の額面年収に対する総返済負担率は異なります。

## 4. 教育資金の勘定

### 目標方式

第n子について、出生予定年から設定年齢までの月額を逆算します。積立したお金は**教育積立残高（目的別）**として管理し、設定年齢以降の実際の学費へ充当した場合は現金支出をその分減らします。運用利回りは0％想定、積立は1円単位で切り上げます。積立資産を二重に足さないよう、「現金＋NISA＋その他投資」とは別表示します。

### 学資保険料の手入力

保険契約の満期金額と受取年が未知のため、保険料支出だけを計上します。満期保険金の自動推定は行わず、契約に合わせて受取イベントを登録する必要があります。目標方式の教育基金と同一の受取を手動イベントとして重複登録しないでください。

## 5. 入力不足と取り扱い上の制限

食費・光熱費が未入力で「その他生活費」にも金額がなければ、金額は暫定計算とし**物件購入の適否判定は保留**します。逆に、旧「その他生活費」と費目別の生活費が重複していないか警告します。利用者の入力値は警告のために自動変更しません。

以下は精密に見積もれる情報がないため、結果を保証できません。

- 退職年齢、退職金、年金・老後収入の個別設定
- 金利変動による返済額の実際の見直しルール（+1％は再借入比較）
- 物価・教育費の上昇、住宅修繕の一時的な大規模支出
- 金融機関の審査金利、諸費用融資、団信条件、住宅ローン控除
- 現金貯蓄の目標逆算後に起きる結婚式・新婚旅行等の一時支出による目標未達

住宅購入判断では、**月返済目安、年別の現金残高、購入月の現金、教育費ピーク、完済時年齢**を必ずセットで確認してください。

## r55：夫婦別の貯金・全額控除後の残額

初期の現金貯金は **夫の預貯金残高 + 妻の預貯金残高** で計算し、給与・投資とは区別します。
過去の保存データが「夫婦合計」のみだった場合は、合計を失わないよう夫の欄に暫定配置し、必ず夫婦別の実数へ配分する注意を表示します。両方を登録して以後は合計を自動更新し、過去の合計フィールドを二重加算しません。

### 毎月の「全て引いた残額」

`手取り収入 − 生活費（学校費・特別費を含む） − 住宅費（ローン元金＋利息・維持費） − NISA等投資積立 − 現金貯金の確保目標 − 予備費の確保目標`

- 正の値は自由に使える計画余力、負の値は計画上の不足として **赤字・赤色** で表示します。
- 現金貯金と予備費は支出ではなく**現金を取り分ける目標**です。月末の現金残高からは再度控除せず、月次現金増減（給与−消費支出−投資）と区別します。
- 現金貯金の目標年数が終了した年には、以後その目標金額の月次控除を行いません。
- 月次の円グラフには「現金貯金」「予備費」「最終残額」を別分類で示します。支出・投資・現金確保を合計した割合は100％を超える場合があります。これは支出超過を表し、残額のマイナスは画面で明示します。

### 借入元金と金利込み返済額

- 借入元金（利息を含まない金額）を緑色系、元金＋利息の月返済額と金利込み総返済額を **オレンジ** で表示。
- `金利込み総返済額 = 金利込みの毎月返済額 × 返済月数`。
- `利息の総額 = 金利込み総返済額 − 借入元金`。
- 住宅維持費はローン返済額とは別で、家計の「住居費」へ加えます。

本計算は支出・収入の登録値にもとづくシミュレーションです。金融機関の審査による実際の借入上限ではありません。


## r56：生活・子ども費の内訳が欠けない表示

- 月収支の「生活・子ども」は、食費・光熱費・通信・車などの一般生活費に加え、年齢条件を満たす子どもの生活費、保育料、子ども保険、学資保険・教育積立、学校費（月割り）、年払い支出（月割り）を含みます。
- 出産前の年は子ども関連の費用が0円です。この場合、最初に計上する出生予定年を内訳内に表示します。
- 合計は **各表示項目の全件合計** と照合します。数値が食い違えば明細見出しに「合計差」を赤字表示します。
- 4列の固定内訳枠で見切れる項目が生じないよう、短い画面は4件ずつ、長い画面は8件ずつ表示し、「1/○」でページ切替できるようにします。円グラフの大きさ、位置、内訳枠の高さ、文字の起点、項目ピッチは変えません。
- 子ども費が行の最後に隠れないよう、子ども保険・教育積立・子どもの生活費・保育料・学校費・出産費を最初に配置します。金額の集計方法は変更しません。
- **年収支の「教育・イベント」** には学校・大学費用を含みます。月収支の「生活・子ども」に表示する年払い学校費の月割りと同じ元データを利用し、二重計算しません。


## r57：内訳レイアウトの再検証

生活・子ども内訳では固定4件/ページを撤廃し、表示時にカードの高さを測定して、4列×38pxのセル数を計算する。円グラフと内訳カードの寸法は固定したまま、収まらない項目だけページ切替で確認できるようにする。

## r58：公的情報との照合と計算モデルの是正（2026-10-28）

### 1. 住宅価格・借入額・購入時現金を別勘定にした

- **物件価格 P** と **現金頭金 D** を入力し、`D = min(P, max(0, 入力頭金))`、**住宅ローン元金 = P − D** とする。
- 元利均等の月返済は `M = (P−D) × r / (1−(1+r)^(-n))`（年利0%の場合 `(P−D)/n`）。表示の金利込み総額は丸めた月返済額×返済回数で整合させる。
- 購入月の現金から**頭金＋諸費用（物件価格の7%という仮定）**を一度だけ差し引く。頭金を費用として二度控除しない。
- 家計から計算した物件価格の参考上限は `返済余力から逆算した借入元金＋同じ頭金`。金融機関の融資承認額ではない。
- 住宅ローン控除・ボーナス返済・変動金利の5年/125%ルール・諸費用を借入れるケースは自動考慮しない。
- 家計上の月返済余力は手取り給与−日常支出−教育費−維持費−希望積立−予備費で計算し、賞与は通常の月返済原資には組み込まない。

### 2. 基準年だけで「安全」と判定しない

- 将来の最も余裕が小さい年は **将来のローン支払い前余力 − 実際に選んだ物件の月返済** を赤字判定とする。従来の「将来のローン支払い前余力が負か」だけの条件では支出超過を見逃す。
- 月手取り以外に賞与等の収入がある場合も、その楽観値で長期固定費の上限を上げない。年次現金予測で実際の入金を確認する。
- **購入月末の現金残高**を年次・月次予測から取り出し、独自の参考値である生活費6か月分の防衛資金と比較。防衛資金は銀行の承認基準ではない。
- 基本金利に対し**借入時から年利＋1%**で同じ期間返済した場合を比較する。これは変動型ローンの途中改定や銀行の審査金利を再現しない。
- 「30%・35%」の数値はフラット35の**額面年収に対する全借入の総返済負担率基準**。手取りだけを登録する本アプリでは、額面年収および他の借入の申込上の算定方法を満たさないため審査結果を自動算定しない。

### 3. 児童手当を任意で制度額計算できるようにした

入力は「手動で設定（従来の仕様、既存データ維持）」または「制度額から概算」から選べる。**自動計算モードは明示選択したときだけ**有効になる。

2024年10月以降の制度額を参考に、第一子・第二子は3歳未満15,000円/月、3〜17歳10,000円/月、第三子は30,000円/月として、偶数月に2か月分を計上する。支給停止・申請月・出生月・誕生日・第三子のカウント要件（22歳年度末の兄姉の扶養条件）は簡易化しているので、厳密な給付見積ではない。子どもの人数はこのアプリの上限3人としている。

### 4. 物価上昇率は入力任意、ゼロを既定値に維持

`生活費の年間上昇率` と `教育費の年間上昇率` を別々に設定できる。数値入力時、現在年から経過した年数 `t` について `費用(t)=現在基準額×(1+率)^t` とする。

- 生活費率：食費・光熱費・通信・子どもの生活費・保育料などの通常支出に適用。借入返済額、保険契約料、教育資金への積立額は物価連動しないものとして扱う。
- 教育費率：小・中・高・大学のベースライン学費と教育基金からの充当額に整合して適用。幼児の保育料は生活費率の対象。
- 初期設定は従来の予測を黙って書き換えないため0%。将来の物価が0%と確定しているという意味では**ない**。物価上昇・賃金の将来変動、仕送り・下宿費、住宅の大規模修繕は個別条件を登録するか追加の安全余裕で考える。
- 日常生活費は一定の上昇率でも、投資リターンは保証されず、給与が同率で増加するとも限らない。

### 5. 教育費ベースラインの性格

公立小学校34万円/年、公立中学校55万円/年、公立高校60万円/年などは学習費調査を参照した**丸めた計画値**。私立高校135万円/年、国公立大学125万円/年、私立大学185万円/年は通学・教材・追加費用の予備を含む**アプリのモデル仮定**であり、各校の請求額や文部科学省の調査平均そのものではない。

- 令和5年度「子供の学習費調査」は2026年1月に一部訂正されている。生徒・家庭ごとの実額を個別に設定できるようにすることが精度向上には必要。
- 2025年度私立大学初年度納付金の調査平均は1,507,647円。アプリの185万円はこれと同じ定義ではなく、生活費・通学費・教材等のバッファを含む保守的な仮定。自宅外仕送りを含むかは個別判断。

### 6. 独立検算

`node --test tests/finance.test.cjs` をCIで実行。金利ゼロの割算、元利均等の正方向・逆方向、頭金と諸費用一回計上、年現金と月現金の一致、児童手当の年齢別支給額・隔月入金、子ども教育基金と学費、インフレを設定したときの各費目の複利、将来最低余力からの実ローン控除を確認する。
