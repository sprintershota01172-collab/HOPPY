# ほっぴーくん / HOPPY

夫婦で使う家探し・比較・人生設計のためのスマートフォン向けPWA。

**現在の実装: フェーズ1（物件メモと○△×比較）**。シミュレーション、スケジュール、自動同期は未実装です。

## アプリを開く

GitHub Pages のデプロイが有効な場合:

https://sprintershota01172-collab.github.io/HOPPY/

Pagesの公開には、GitHubリポジトリの **Settings → Pages → Build and deployment → Source: GitHub Actions** の設定が必要な場合があります。.github/workflows/pages.ymlは main 更新時に静的ファイルを配信します。公開できない場合は Actions タブからデプロイ結果を確認してください。

### iPhoneにインストール

SafariでURLを開き、「共有」→「ホーム画面に追加」。最初の一度はオンライン接続が必要です。その後は、端末にキャッシュされたアプリと登録データをオフラインで使えます。

## フェーズ1に含まれる機能

- **物件**：登録・編集・削除、価格/住所/種別/築年数/面積/間取り/最寄駅徒歩/ステータス/タグ、検索・並び替え、カード/4件グリッド・詳細3画面。
- **メモ**：良かった点/気になる点のページ式メモ、質問リストの追加・削除・確認済み。ノートは高さを超えたら次ページへ分割。
- **写真**：複数添付、1枚表示・ページ移動・削除、画像縮小後 IndexedDB に保存。
- **比較**：最大3件横並び、比較項目の追加/削除/順序変更、重要度★1〜3、夫・妻・ふたりの表示、○/△/×の手動採点、数値条件による自動採点、最終ページの加重点数ランキング。
- **バックアップ**：物件情報・採点・写真を1つのJSONでエクスポート/インポート（インポートは置換）。
- **端末UI**：縦横スクロールなし、固定4タブ、ページ送り/スワイプ、フェード＋スライド、視差効果を減らす設定に対応。
- **PWA**：Service Workerとインストール用マニフェスト、オフライン起動。

最初は物件0件で始まります。「サンプル3件で試す」では架空の検討物件を追加できます。サンプルの価格等は実際の家計データではありません。

## 保存・セキュリティに関する注意

**共同編集・ログイン制限はまだありません。** 現フェーズはブラウザ/端末単位の保存です。夫婦で同じデータを見るには、バックアップを書き出して相手側で取り込む必要があり、取り込みは既存データを上書きします。

- 物件・採点：端末内 localStorage
- 写真：端末内 IndexedDB
- ソースコード：現在のGitHubリポジトリは public です。プログラムは公開されていますが、ユーザーが登録した金額や写真はGitHubにアップロードされません。
- 公開Pagesサイトにはログインがなく、URLを知っている人も空のアプリを開けます。他人の端末から登録済みデータを取得する仕組みはありません。
- Safariのサイトデータ消去やストレージ制限等でデータが消える可能性があるため、定期的に「…」→「JSONをエクスポート」してください。
- iOSの通知、夫婦同期、アカウント認証は将来のフェーズです。

## 実装構成

外部ライブラリ不要。index.html、styles.css、app.js、manifest.webmanifest、sw.js、icon.svg、icon-192.png だけで動きます。HTTP上でのService Workerは動作しないため、オフライン確認は GitHub Pages（HTTPS）または localhost 上で実施してください。

## 受け入れチェックリスト（実機推奨）

1. iPhone SE相当の小画面と一般的なiPhoneで、物件カード/比較表/すべての編集ステップが画面外にはみ出さない。
2. 物件を新規登録 → 編集 → 再起動して保存を確認 → 削除。
3. メモを入力してページ追加・ページ送り → 質問のチェック → 再起動して維持を確認。
4. 写真を複数枚添付 → オフライン起動 → 写真が表示される。
5. 3物件を選んで10項目を夫・妻別に採点 → 重要度変更後ランキングが更新される。
6. 価格/駅距離の自動判定の基準値を設定し、自動判定/手動上書き/上書き解除を確認。
7. JSON出力 → 別ブラウザで取り込み → 物件・採点・写真が再現される。
8. iOS「視差効果を減らす」をオンにして短い画面遷移を確認。
