# ほっぴーくん / HOPPY

夫婦で使う家探し・比較・人生設計のためのスマートフォン向けPWA。

**現在の実装: フェーズ1（物件メモと○△×比較）**。シミュレーション、スケジュール、自動同期は未実装です。

## アプリを開く

GitHub Pages のデプロイが有効な場合:

https://sprintershota01172-collab.github.io/HOPPY/

Pagesの公開には、GitHubリポジトリの **Settings → Pages → Build and deployment → Source: GitHub Actions** の設定が必要な場合があります。.github/workflows/pages.ymlは main 更新時に静的ファイルを配信します。公開できない場合は Actions タブからデプロイ結果を確認してください。

### iPhoneにインストール

SafariでURLを開き、「共有」→「ホーム画面に追加」。最初の一度はオンライン接続が必要です。その後は、端末にキャッシュされたアプリと登録データをオフラインで使えます。

## フェーズ1に含まれる機能

- **物件**：登録・編集・削除、価格/住所/種別/築年数/面積/間取り/最寄駅徒歩/ステータス/タグ、検索・並び替え、カード/4件グリッド・詳細3画面。
- **メモ**：良かった点/気になる点のページ式メモ、質問リストの追加・削除・確認済み。ノートは高さを超えたら次ページへ分割。
- **写真**：複数添付、1枚表示・ページ移動・削除、画像縮小後 IndexedDB に保存。
- **比較**：最大3件横並び、比較項目の追加/削除/順序変更、重要度★1〜3、夫・妻・ふたりの表示、○/△/×の手動採点、数値条件による自動採点、最終ページの加重点数ランキング。
- **バックアップ**：物件情報・採点・写真を1つのJSONでエクスポート/インポート（インポートは置換）。
- **端末UI**：縦横スクロールなし、固定4タブ、ページ送り/スワイプ、フェード＋スライド、視差効果を減らす設定に対応。
- **PWA**：Service Workerとインストール用マニフェスト、オフライン起動。

最初は物件0件で始まります。「サンプル3件で試す」では架空の検討物件を追加できます。サンプルの価格等は実際の家計データではありません。

## 地価ランキング（r73〜）

愛知県全域（名古屋市は16区ごと）と岐阜県の多治見市・土岐市・瑞浪市・恵那市・可児市・御嵩町・美濃加茂市を、国の公式オープンデータで比較する画面です。下のメニューの「地価」（グラフのアイコン）から開きます。

- **ランキング8種類**：坪単価（地価公示／地価調査／両方）・前年比・5年/10年の上昇率・実勢の土地取引（坪単価の中央値）・中古戸建の取引価格・予算で買える坪数/土地総額（○△×）・地点・駅。すべて「高い順／安い順」、単価は「㎡／坪」を切替。
- **絞り込み**：全域／名古屋市／尾張／知多／西三河／東三河／東濃・中濃／多治見◯km（もう一度押すと10→20→30km）。★を付けた市区町村は先頭に固定できます。
- **詳細カード**：10年の推移、公示・調査・実勢・商業地の比較、地点トップ5、上昇率、多治見駅からの距離、50坪の土地総額。「物件と比べる」で物件の登録・詳細へ。
- **物件比較との連携**：物件の「基本情報を編集 → 土地」で市区町村・土地面積（坪）・土地価格を入れると、比較表の「土地の割安度（相場比）」が自動で○△×になります（相場より5%以上安い○／±5%以内△／5%以上高い×。しきい値は地価の⚙で変更）。相場は実勢の取引中央値（5件以上）を優先し、無ければ地価公示・地価調査の平均を使います。
- **人生設計との連携**：FPの「購入の目安」−建物予算（初期値2,500万円）＝土地予算。FP未設定なら地価の⚙で購入額を入力します。
- **オフライン**：取得したデータは端末（IndexedDB）に保存され、通信できなくても前回のデータで表示します。

### 仕組み（APIキーはアプリに置かない）

```
[🔄 最新にする] → GitHub API で workflow_dispatch
   → Actions「地価データ更新」(.github/workflows/update-landprice.yml)
      → scripts/fetch-landprice.mjs が不動産情報ライブラリAPIから取得・集計
      → data/landprice.json をコミット → GitHub Pages を再デプロイ
   → アプリが新しいJSONを読み込んで「○件の市区町村を更新しました」
```

- 自動実行：毎週月曜の朝（JST 6:17）。中身が前回と同じならコミットしません。
- 公表時期（地価公示＝3月下旬、地価調査＝9月中旬〜下旬、取引価格＝1・4・7・10月下旬）を過ぎてもデータが古いと、ボタンが光り「新しい地価が公表されたかも」と表示します。
- 過去年の地点データは `data/archive/` に、地点の無いタイルは `data/tile-cache.json` に保存し、次回から取得しません（年1回は全タイルを再走査）。初回だけ約800タイル×11年分を取得するため30〜60分かかります。2回目以降は公表があった年だけを取得します。
- 初回のActions実行前は `data/landprice-seed.json`（公表資料の平均値。一部の市区町村のみ）を表示します。

### 事前にやること（1回だけ）

1. **APIキーを申請**：[不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/) の「API利用申請」から申し込む（無料）。数営業日でキーがメールで届きます。
2. **APIキーを登録**：GitHub の HOPPY リポジトリ → **Settings → Secrets and variables → Actions → New repository secret**。Name は `REINFOLIB_API_KEY`、Secret に届いたキーを貼り付けて保存。
3. **初回の取得**：リポジトリの **Actions → 地価データ更新 → Run workflow**（Branch: main）。30〜60分ほどで data/landprice.json ができ、Pagesに反映されます。
4. **GitHubトークンを作る**（アプリのボタンから更新したい場合）：GitHub 右上のアイコン → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access：**Only select repositories → HOPPY**
   - Repository permissions：**Actions：Read and write**、**Contents：Read-only**（Metadata は自動でRead-only）
   - 有効期限は任意（切れたらアプリに「期限が切れています」と表示されます）
5. **アプリに入力**：地価画面の ⚙ → 「ワンタップ更新（GitHub）」にトークンを貼って保存。トークンはその端末の中だけに保存され、バックアップJSONにも含まれません。

### 手動で更新するには

- アプリ：地価画面の右上「🔄 最新にする」。進み具合は「準備中 → 取得中 → 反映中 → 完了」で表示されます。トークン未設定の端末では、公開中の最新JSONを読み直すだけです。
- GitHub：**Actions → 地価データ更新 → Run workflow**。全タイルを再走査したいときは「全タイルを再走査する」にチェック。
- パソコン：`REINFOLIB_API_KEY=xxxx node scripts/fetch-landprice.mjs`（Node 20以上。`--full` で全タイル再走査）

### 算出方法と検算

- 住宅地の平均＝各地点価格の単純平均。前年比＝継続地点の変動率の平均（公式と同じ算出方法）。5年・10年＝同じ地点番号・ほぼ同じ位置（300m以内）の地点だけで比較。坪単価＝㎡単価×3.305785。地点数3未満は「参考」。
- 実勢＝取引価格（XIT001）の「宅地(土地)」直近4四半期の坪単価の中央値（上下5%を除外）。5件未満は「参考」、直近8四半期で5件以上あればそちらを使います。中古戸建＝「宅地(土地と建物)」の取引総額の中央値。
- 多治見駅からの距離＝その市区町村の地点の重心と多治見駅付近（北緯35.334・東経137.121）の直線距離。
- 集計のたびに7章の検算値（愛知県2026年地価公示 132,130円/㎡ など）と比べ、±5%を超えるとActionsのログに警告を出します。結果はアプリの「データについて」でも確認できます。
- 検算で差が出る可能性があるもの：**岐阜県の平均**は対象7市町だけの集計なので、県全体の公表値（地価公示 46,640円/㎡）とは一致しません（参考扱い）。住宅地には「市街化調整区域内の現況宅地」を含めていません。また、APIキーが届く前のため、実データでの検算はまだ行っていません（模擬データで集計ロジックを検証済み：`node --test tests/landprice.test.cjs`）。初回実行後に差が±5%を超えた場合はここに理由を追記してください。

> このサービスは、国土交通省不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません。
> 地価公示・地価調査は鑑定評価による標準的な更地価格で、実際の売り出し価格とは異なります。

## 保存・セキュリティに関する注意

**共同編集・ログイン制限はまだありません。** 現フェーズはブラウザ/端末単位の保存です。夫婦で同じデータを見るには、バックアップを書き出して相手側で取り込む必要があり、取り込みは既存データを上書きします。

- 物件・採点：端末内 localStorage
- 地価データ：端末内 IndexedDB（GitHubトークンは localStorage の別キー。バックアップには含めない）
- 写真：端末内 IndexedDB
- ソースコード：現在のGitHubリポジトリは public です。プログラムは公開されていますが、ユーザーが登録した金額や写真はGitHubにアップロードされません。
- 公開Pagesサイトにはログインがなく、URLを知っている人も空のアプリを開けます。他人の端末から登録済みデータを取得する仕組みはありません。
- Safariのサイトデータ消去やストレージ制限等でデータが消える可能性があるため、定期的に「…」→「JSONをエクスポート」してください。
- iOSの通知、夫婦同期、アカウント認証は将来のフェーズです。

## 実装構成

外部ライブラリ不要。index.html、styles.css、app.js、manifest.webmanifest、sw.js、icon.svg、icon-192.png だけで動きます。HTTP上でのService Workerは動作しないため、オフライン確認は GitHub Pages（HTTPS）または localhost 上で実施してください。

## 受け入れチェックリスト（実機推奨）

1. iPhone SE相当の小画面と一般的なiPhoneで、物件カード/比較表/すべての編集ステップが画面外にはみ出さない。
2. 物件を新規登録 → 編集 → 再起動して保存を確認 → 削除。
3. メモを入力してページ追加・ページ送り → 質問のチェック → 再起動して維持を確認。
4. 写真を複数枚添付 → オフライン起動 → 写真が表示される。
5. 3物件を選んで10項目を夫・妻別に採点 → 重要度変更後ランキングが更新される。
6. 価格/駅距離の自動判定の基準値を設定し、自動判定/手動上書き/上書き解除を確認。
7. JSON出力 → 別ブラウザで取り込み → 物件・採点・写真が再現される。
8. iOS「視差効果を減らす」をオンにして短い画面遷移を確認。
