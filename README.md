# 地価調べ君（リポジトリ名：HOPPY）

愛知県全域（名古屋市は16区ごと）と岐阜県の多治見周辺7市町の地価を調べてくらべる、スマートフォン向けのアプリ（PWA）です。

- **ランキング**：坪単価・前年比・5/10年の上昇率・予算で買える坪数・地点・駅
- **相場**：条件を選んで「土地＋建物＋付帯工事＋諸費用」の総額の目安を計算
- **メーカー**：ハウスメーカー・工務店41社（全国系28社＋愛知・岐阜の地元13社）の坪単価・構造・特徴・注意点・保証
- **土地**：地域の特徴と、土地の条件（駅距離・道路・角地・用途地域・広さ）で価格がどう変わるか

（旧名：ほっぴーくん。2026年11月にアプリ名を「地価調べ君」に変え、r77で物件・比較・FP・予定・メモ・更新の画面を削除して地価の機能だけにしました。家探しノート時代に端末へ保存したデータは消していません。）

## アプリを開く

https://sprintershota01172-collab.github.io/HOPPY/

iPhoneでは Safari で開き、「共有」→「ホーム画面に追加」。一度開けばオフラインでも前回のデータで表示できます。

## 構成

外部ライブラリ不要。index.html・styles.css・app.js・sw.js・manifest.webmanifest と data/ のJSONだけで動きます。

- 設定（★お気に入り・表示の切替・予算・相場の条件）：端末の localStorage（`chika-shirabe-v1`）
- 地価データ：端末の IndexedDB（`hoppy-landprice-v1`）
- GitHubトークン（任意）：端末の localStorage の別キー

## 地価ランキング（r73〜・APIキー不要）

愛知県全域（名古屋市は16区ごと）と岐阜県の多治見市・土岐市・瑞浪市・恵那市・可児市・御嵩町・美濃加茂市を、国の公式オープンデータで比較する画面です。

- **ランキング**：坪単価（地価公示／地価調査／両方）・前年比・5年/10年の上昇率・予算で買える坪数/土地総額（○△×）・地点・駅。すべて「高い順／安い順」、単価は「㎡／坪」を切替。実勢（土地取引）と中古戸建は、任意のAPIキーを登録した場合だけ表示されます。
- **絞り込み**：全域／名古屋市／尾張／知多／西三河／東三河／東濃・中濃／多治見◯km（もう一度押すと10→20→30km）。★を付けた市区町村は先頭に固定できます。
- **詳細カード**：10年の推移、公示・調査・商業地の比較、地点トップ5、上昇率、多治見駅からの距離、50坪の土地総額。「この市区町村で総額を計算」で相場画面へ。
- **予算**：⚙で「家の購入予算」と「建物予算（初期値2,500万円）」を入れると、土地に使える予算で○△×を判定します。
- **オフライン**：取得したデータは端末（IndexedDB）に保存され、通信できなくても前回のデータで表示します。

### 相場シミュレーター・メーカー図鑑・土地ガイド（r76〜）

画面上部の「ランキング／相場／メーカー／土地」で切り替えます。

- **相場**：市区町村・土地の広さ・駅からの距離・用途地域・前面道路の向きと幅・角地・建物の延床・ハウスメーカー・仕様のグレードを選ぶと、総額の目安（土地代＋建物本体＋付帯工事＋諸費用）を出し、⚙の購入予算と比べて○△×を付けます。
  - 土地：条件に合う標準地が市区町村内に3地点以上あればその中央値。足りなければ、同じ地域（なければ全域）の似た条件の地点が「市区町村の平均より何%高い／安いか」を使って推計します（「推計」と表示）。
  - 建物：各社の本体の坪単価（下限・目安・上限）×延床。付帯工事は本体の25%、諸費用は合計の7%（総額の内訳の一般的な目安：本体70〜80%・付帯15〜20%・諸費用5〜10%）。
- **メーカー**：全国系28社（積水ハウス・大和ハウス・ヘーベルハウス・住友林業・セキスイハイム・パナソニック ホームズ・トヨタホーム・ミサワホーム・三井ホーム・スウェーデンハウス・三菱地所ホーム・一条工務店・アイ工務店・住友不動産・日本ハウスHD・無印良品の家・ヤマト住建・ヤマダホームズ・桧家住宅・タマホーム・アキュラホーム・クレバリーホーム・アイフルホーム・ユニバーサルホーム・アイダ設計 ほか）と、愛知・岐阜の地元工務店13社（クラシスホーム・アールギャラリー・善匠・ニケンハウジング・ブルーハウス・アーキテックス・オカザキホーム・玉善・中部住研・野村工務店・フジケン・丸七ホーム・渡邊工務店、岐阜はヤマカ木材・新和建設・ひだまりほーむ）。「全国／愛知／岐阜／鉄骨」で絞り込めます。坪単価の目安、構造・工法、特徴、注意点、保証、向いている人。岐阜の3社は記事に坪単価の記載がないため、岐阜県の相場（50〜90万円）を「仮」として表示しています。出典はアプリの各社ページに記載（2026年11月15日確認）。
- **土地**：地域の特徴（集計値と2026年地価公示の県発表）と、土地の条件（駅距離・道路の向き・角地・道路幅・用途地域・広さ）ごとに「同じ市区町村の平均との差」を実データで表示。標準地は典型的な土地が選ばれるため、角地などは例が少なく参考値です。

### 仕組み（登録・APIキーは不要）

```
毎週月曜の朝（JST 6:17）／GitHubの Run workflow／アプリの「🔄 最新にする」
   → Actions「地価データ更新」(.github/workflows/update-landprice.yml)
      → scripts/fetch-landprice.mjs が国土数値情報（国土交通省）から
        地価公示 L01 と 都道府県地価調査 L02（愛知・岐阜）の zip をダウンロードして集計
      → data/landprice.json が変わったときだけコミット → GitHub Pages を再デプロイ
   → アプリが新しいJSONを読み込む
```

- 国土数値情報のファイルには各地点の過去の価格も入っているため、10年の推移や5年・10年の上昇率も同じファイルから計算します。属性の列番号は年度で変わるため、中身（年度・価格・コードの並び）から列を自動判定します。
- 公表時期（地価公示＝3月下旬、地価調査＝9月中旬〜下旬）を過ぎてもデータが古いと、ボタンが光り「新しい地価が公表されたかも」と表示します。
- 1回の実行は1分ほどです。中身が前回と同じならコミットしません。

### 使い方

- **何もしなくてOK**：毎週月曜の朝に自動で最新になります。アプリは開くたびに新しいデータがあるか確認します。
- **今すぐ更新したいとき**：GitHub の [Actions → 地価データ更新](https://github.com/sprintershota01172-collab/HOPPY/actions/workflows/update-landprice.yml) → **Run workflow** → 緑の **Run workflow**。1〜2分で終わり、数分後にアプリへ反映されます。
- **アプリのボタンから更新したいとき（任意）**：GitHub で Fine-grained トークンを作成（右上アイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access：Only select repositories → HOPPY、Permissions：Actions＝Read and write、Contents＝Read-only）→ 地価画面の ⚙ に貼って保存。トークンはその端末だけに保存され、バックアップJSONにも含まれません。未設定でも「最新にする」は公開中のデータを読み直します。
- **実勢・中古戸建も見たいとき（任意）**：[不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/api/request/) でAPIキーを申請し、このリポジトリの Settings → Secrets and variables → Actions に `REINFOLIB_API_KEY` として登録すると、取引価格（XIT001）も集計されます。
- パソコンから：`node scripts/fetch-landprice.mjs`（Node 20以上、`unzip` コマンドが必要）

### 算出方法と検算

- 住宅地の平均＝用途区分「住宅地」の各地点価格の単純平均（市街化調整区域内の現況宅地は含めない）。前年比＝継続地点の変動率の平均（公式と同じ算出方法）。5年・10年＝同じ地点の過去の価格と比較（当時選定されていない地点は除外）。坪単価＝㎡単価×3.305785。地点数3未満は「参考」。
- 多治見駅からの距離＝その市区町村の地点の重心と多治見駅付近（北緯35.334・東経137.121）の直線距離。
- 対象の市区町村コードはスクリプト内の一覧（全国地方公共団体コード）で確定します。APIキーを登録した場合は XIT002 の一覧と名前を照合し、ずれがあればログに警告を出します。
- **検算結果（2026年11月15日の実行）**：愛知県 地価公示 132,131円/㎡（公表 132,130）・地価調査 122,707（122,706）、岐阜県 地価公示 46,640（46,640）・地価調査 33,337（33,337）、多治見市 地価公示 38,938（38,937）・地価調査 36,462（36,461）、可児市 31,600（31,600）、小牧市 92,196（92,195）、春日井市 2025年地価調査 118,382（118,381）。すべて差は0%（1円の差は四捨五入）。結果はActionsのログとアプリの「データについて」でも確認できます。

> 出典：「国土数値情報（地価公示データ・都道府県地価調査データ）」（国土交通省）を加工して作成。
> 地価公示・地価調査は鑑定評価による標準的な更地価格で、実際の売り出し価格とは異なります。
> 取引価格を取得した場合：このサービスは、国土交通省不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません。

## 地区別の地価（r79）

市区町村の詳細 →「地区ごとの地価を見る」で、町名ごとの平均地価（住宅地／商業地、高い順・安い順）を表示。町名をタップすると、その町の各地点（価格・前年比・5年変化・駅距離・用途地域・前面道路・面積）を確認できます。地区＝地価公示・地価調査の地点の所在地（町名）でまとめたものです。

## 通勤コスト（r79〜r80）

夫・妻それぞれに勤務先と通勤方法を設定できます（r80）。2人分の時間・費用は合計して比較します。「通勤」タブで勤務先（住所・駅名を国土地理院の住所検索で、または市区町村から選択）と通勤方法を設定すると、各市区町村・各地区からの通勤時間と費用を計算します。

- 車：道のり＝直線距離×1.3、時間＝道のり÷平均速度＋5分、月の燃料代＝往復道のり×出勤日数÷燃費×ガソリン単価（初期値164円/L：2026年7月の愛知県平均付近）
- 電車：道のり＝直線距離×1.25、時間＝15分（徒歩・待ち）＋道のり÷40km/h。定期代を入れればその金額、未入力なら距離から推計
- 自転車：時速15km、費用0円
- 通勤手当を差し引いた自己負担で、月・年・指定年数の合計を算出。「土地＋通勤」で土地代と通勤費の合計順に並べ替え可能

## 地図・比較・用語ガイド（r81）

- **地図**：地価公示・地価調査の地点を国土地理院の地図（淡色地図）に表示。色は坪単価（〜10万／〜20万／〜40万／〜80万／80万円〜）。ドラッグで移動、ピンチ・＋−で拡大縮小、拡大すると坪単価を表示。地点をタップすると価格・前年比・5年変化・駅距離・用途地域が出て、市区町村や地区の画面へ移れます。夫・妻の勤務先もピンで表示。市区町村の詳細・地区の画面の「地図で見る」からも開けます。
- **比較**：☆を付けた市区町村と地区（地区の画面の☆）を横に並べ、住宅地平均・前年比・5年変化・土地代・総額の目安（相場タブの設定）・通勤時間・通勤費・土地＋通勤を比較。いちばん有利な値は緑で表示。
- **用語ガイド**：「土地」タブの「用語」に、地価公示と地価調査の違い（表で比較）、標準地・基準地、坪単価、変動率、実勢価格、路線価、固定資産税評価額、用途地域、建ぺい率・容積率、接道義務、角地、道路の向き、旗竿地、付帯工事費・諸費用、建物の坪単価をまとめています。市区町村の詳細の「公示と調査」からも開けます。

## 操作のシンプル化（r82）

- 画面の切り替えを下の5つのタブ（ランキング・地図・比較・計算・知る）にまとめました。「計算」は家の総額／通勤、「知る」はメーカー／地域／土地の条件／用語を上で切り替えます。
- エリアの絞り込みはボタン8個から「📍 エリア ▾」の1つの選択に。新たに「★候補だけ」を追加し、「多治見20km」は廃止（岐阜は「岐阜（東濃・中濃）」で選べます）。地図ではエリアを選ぶとその範囲に自動で拡大します。
- 「最新にする」と「使う地価（公示・調査・両方）」「★候補を先頭に」は ⚙ 設定へ移動。新しい地価が出ていそうなときは ⚙ にオレンジの点が付きます。
- 一覧から「多治見からの距離」の表示をなくし、地域名だけにしました。

## メーカーの性能・仕様（r83）

「知る」→「メーカー」の各社に、性能の項目を追加しました。

- 一覧：耐震3・制震（免震可）・断熱等級・気密測定・保証年数のバッジを表示。並べ替えは「坪単価が安い／高い・耐震が強い・断熱が高い・保証が長い」から選択。
- 詳細の「性能・仕様」：耐震・断熱・気密・保証・価格の5項目を◎○△で表示し、耐震／制震・免震／断熱（等級・UA値）／気密／構造／外壁・耐久／冷暖房・設備／工期／長期優良住宅／保証を一覧に。
- 値は代表的な商品の公表値や比較記事（CREX「ハウスメーカーUA値ランキング20社」「地震に強いハウスメーカー耐震性ランキング15選」、オリコン、各社資料）によるもので、確認できないものは「要確認」と表示。正式な等級は住宅性能評価書で確認してください。

## 土地と建物の比率・お金の診断（r84）

- 「計算」→「家の総額」に2つの決め方：
  - 広さから総額を出す（従来）：結果に「土地◯%：建物◯%（東海圏の平均27:73）」を表示。
  - 予算を土地と建物に分ける：総予算と土地の割合（スライダー5〜70%）から、買える土地の坪数と建てられる建物の坪数を計算。総予算から諸費用7%を引き、残りを土地と建物（本体＋付帯工事25%）に配分。希望の土地の広さに必要な割合へワンタップで合わせられます。
- 土地の条件（駅・用途地域・道路・角地）は「土地の条件 ▾」にまとめて、必要なときだけ開く形に。
- 「計算」→「お金の診断」：世帯年収・自己資金・金利（変動1.2%／全期間固定3.81%：2026年11月の目安）・返済年数から、借入額・月々の返済・返済負担率を計算し、アドバイスを表示（返済負担率25%の目安、金利+1%の影響、諸費用と自己資金、年収倍率、県平均との比較、土地と建物の比率、予備費）。
- 「みんなの平均」：住宅金融支援機構「2025年度フラット35利用者調査」（2026年7月公表）の土地付注文住宅の平均（愛知県5,830万円・岐阜県4,939万円・東海圏5,325万円〈土地27%〉・全国5,313万円、世帯年収742万円、年収倍率7.8倍、返済負担率26.4%、自己資金481万円）と比較。

## 広さの目安（r85）

「計算」→「家の総額」の「📏 広さの目安」から、家族の人数・車の台数・階数・庭・建ぺい率を選ぶと、建物（延床）と土地の目安の坪数を計算し、指標と並べて表示。

- 建物：国土交通省「住生活基本計画」の居住面積水準（最低限＝10㎡×人数＋10㎡、都市の目安＝20㎡×人数＋15㎡、ゆとり＝25㎡×人数＋25㎡）。目安には「ゆとり」を使用。
- 土地：建物の1階部分＋車1台15㎡＋庭（小さめ15㎡・広め40㎡）＋すき間（1階の3割）と、建ぺい率から必要な広さの大きいほう。
- 比較の指標：2025年度フラット35利用者調査（注文住宅の延床118.4㎡、土地付注文住宅の敷地247.1㎡、建売の延床100.4㎡・敷地131.5㎡）と、選んだ市区町村の地価公示・地価調査の住宅地の地積の中央値。
- 「この広さで総額を計算」で、相場の土地・建物の広さに反映。予算モードでは、目安より狭いときに注意を表示。

## 性能の見方（r86）

- メーカー一覧の目印を言葉に：「耐震 最高」「揺れ吸収（制震）」「免震も可」「断熱 6/7」「すき間測定」「保証◯年」。
- 「目印の見方 ⓘ」、メーカー詳細の評価タイル・耐震／制震・免震／断熱／気密／保証の行をタップすると「性能の見方」を表示（耐震等級1〜3、耐震・制震・免震の違い、断熱等級4〜7とUA値、気密とC値、保証の年数）。閉じるとメーカー詳細に戻ります。
- 詳細の値も「等級3＝3段階でいちばん強い」「等級6＝7段階で上から2番目」のように意味を併記。用語ガイドにも耐震等級・断熱等級・気密を追加。

## 予算から探す（r87）

「計算」→「予算から探す」で、買える値段（総額）を入れると、建てられる場所とメーカーを紹介します。

- 広さは「広さの目安」（人数・車の台数など）の結果を使用（タップで変更）。エリアの絞り込みも可能。
- 計算：総額から諸費用7%を引き、市区町村の住宅地の平均地価×土地の坪数を引いた残りを建物（本体＋付帯工事25%）に配分し、建物本体にかけられる坪単価を算出。
- おすすめの場所：予算内の市区町村を「大手の上位も／大手も／中堅まで／ローコスト／ギリギリ」で表示。並べ替えは、おすすめ順（中堅以上が建てられる場所を地価が高い＝便利な順）・建物にお金をかけられる順・土地が安い順・通勤が近い順。タップで建てられるメーカー（性能の高い順）と、その市で地価が安めの地区を表示。
- おすすめのメーカー：予算内で建てられるメーカーを性能の高い順に。タップで建てられる場所（通勤が近い順、未設定なら便利な順）を表示。
- 組み合わせをタップすると「家の総額」でその場所・メーカー・広さを計算。

## 月々の返済額から探す（r88）

「予算から探す」は、月々払える額と頭金から総額を計算して提案する形に変更（「計算」タブを開くと最初に表示）。

- 入力：月々払える額・頭金。金利（変動1.2%／固定3.81%、自由入力）と返済年数は「金利◯%・◯年 ▾」で開いて変更（「お金の診断」と共通）。
- 借りられる額＝月々の返済額から元利均等返済で逆算。総額＝借りられる額＋頭金。
- 「総額で入れる」に切り替えると、従来どおり総額から探せます（そのときは月々の返済額を表示）。

## 金利と返済の詳細・キャラクター（r89）

- 「予算から探す」の総額の帯、「お金の診断」の「利息の合計…」から「金利と返済の詳細」を表示。
  - 返済の内訳：借りる額・月々の返済・返す総額・そのうち利息、元金と利息の割合、5年ごとの残高の減り方、1年目の利息の割合と金利+1%の影響。
  - 金利で比べる：0.8〜4.5%で月々・利息の合計・差を一覧に（いまの金利を強調）。
  - 金利の種類：変動（1.2%前後）・10年固定（3%台半ば）・全期間固定（フラット35 3.81%）の特徴と、それぞれの月々・利息。ワンタップで切り替え。返済年数は25〜40年から選択。
- オリジナルキャラクター「地価調べ君」（家の形で虫めがねを持つ）を追加：起動画面・ヘッダー・お金の診断のアドバイス（表情が良い／注意／心配で変化）・予算から探す・広さの目安・性能の見方・空の画面のイラストなど。

## かんたん4ステップ・建売（r90）

「計算」→「予算から探す」を、1画面1つの質問で進む4ステップに作り直し。

1. 月々いくらまで返せる？（−／＋ボタン、8・10・12・15万のワンタップ）。金利・年数は「変える ›」から。
2. 頭金は？（0・100・300・500万のワンタップ）。借りられる額と総額をその場で表示。
3. どんな家にする？（注文住宅／建売住宅／両方くらべる）
4. どのあたりに住みたい？（エリアをタップ）

結果画面の上の「月12万・頭金0万・注文・全域」をタップすると、その質問に戻って変更できます。

- 建売住宅：2025年度フラット35利用者調査の建売住宅（敷地131.5㎡・延床100.4㎡、愛知3,853.5万円・岐阜3,025.2万円）から、県の標準的な地価（中央値）×敷地を差し引いて建物分を推計し、市区町村ごとに「土地40坪×地価＋建物＋諸費用7.5%」で目安を算出。タップで内訳・月々の返済・注文住宅との比較。
- 両方くらべる：市区町村ごとに注文住宅で建てられるランクと建売の目安を並べて表示。
- 結果の確実性のため、注文住宅の諸費用を7%→10%（土地・建物総額の10%が相場）に見直し。建売は物件価格の6〜9%の中間7.5%。

## 気になる土地の登録（r91）

下のタブ「候補」（⭐）→「登録した土地」で、広告やチラシの土地を登録して評価できます（端末内に保存、30件まで）。

- 入力：必須は市区町村・広さ（坪／㎡）・土地の価格の3つだけ。わかれば町名・番地、呼び名、駅まで徒歩、前面道路の幅・向き、用途地域、建築条件、広告URL、メモ。
- 評価：
  - 相場：坪単価を地価の目安（同じ町名の地価公示・地価調査の平均、なければ市区町村の住宅地の中央値）と比べ、0.95倍未満＝割安、1.25倍まで＝相場なみ、それ以上＝高めをゲージで表示（広告価格は地価公示より1〜2割高いのが一般的）。
  - 家を建てた総額（建物は「家の総額」のメーカー・グレード・延床で計算、付帯工事25%・諸費用10%）、月々の返済、予算（予算から探すの総額）内かどうか、通勤時間。
  - 注意点：道路4m未満（セットバック）、北道路／南道路、建築条件付き、市街化調整区域、商業・工業系の地域、駅徒歩10分以内、広さの目安より狭い、など。
- 場所：町名・番地から国土地理院の住所検索で位置を取得（できなければ町名・市区町村の中心）。地図にオレンジの★で表示。
- 「くらべる」：登録した土地を☆の市区町村・地区と並べて、坪単価・土地代・総額・通勤などを比較。

## 使い方ガイド・計算の根拠（r92）

- 初めて開くと「地価調べ君の使い方」を表示。やりたいこと（いくらの家が買える？／この場所・この会社でいくら？／返済は大丈夫？／通勤は？／気になる土地を評価／地価の安い所・高い所／ハウスメーカー／言葉の意味）から選ぶと、その機能へ移動。おすすめの進め方は「予算から探す → 候補を登録 → 総額を計算 → 返済チェック」。ヘッダーの「？」からいつでも表示。
- 各画面の上に「この画面は何をするか」の一行と「使い方」ボタン。使い方には「こんなときに」「手順（番号つき）」「次はこれ（関連機能へ移動）」を表示。
- 名前をわかりやすく：「家の総額」→「総額を計算」、「お金（お金の診断）」→「返済チェック」。
- 返済チェックに「計算の根拠」タブ：①家の総額の内訳 ②借りる額＝総額−頭金 ③月々の返済（元利均等返済の式と月の金利・回数） ④返済負担率＝月々×12÷年収（目安25%、フラット35の審査上限30%/35%） ⑤年収倍率＝総額÷年収（平均7.8倍） ⑥25%に収まる借入額、をあなたの数字で表示。総額がどこから来ているか（「総額を計算」の結果）も明記し、「変える ›」で移動。

## 建売の計算の根拠（r93）

建売の詳細に「計算の根拠」タブを追加。①土地＝市の住宅地の平均坪単価×40坪（131.5㎡＝建売の全国平均の敷地） ②建物＝県の建売の平均価格（2025年度フラット35利用者調査：愛知3,853.5万円・岐阜3,025.2万円）−県の住宅地の中央値×131.5㎡ ③物件価格＝土地＋建物 ④諸費用＝物件価格×7.5%（相場6〜9%の中間） ⑤合計 ⑥月々の返済、をその市の数字で表示。

## 土地の登録をかんたんに（r94）

- 登録は1画面1つの質問で進む形に：①どこ？（よく使う市区町村のボタン＋一覧、町名） ②広さ（㎡で入力が基本。坪にも切り替え可。「＝165.3㎡・約50坪」と換算し、家族・車の台数から見た目安と比べて「狭め／ちょうどいい／かなり広い」） ③値段（坪単価・1㎡あたりを表示し、その辺りの地価の目安と比べて「割安／相場なみ／高め」をその場で表示）→「ここで保存」か ④詳しく（任意）。
- 「広告の文章を貼り付ける」：SUUMOなどの物件ページの文章をコピーして貼り付けると、市区町村・町名・土地面積（㎡／坪）・価格（億・万円）・駅徒歩・道路の幅と向き・用途地域・建築条件・URLを自動で読み取り。
- 一覧・詳細の広さは「165㎡（約50坪）」の形で表示。

## 初心者向けの目安（r95）

- 土地の登録「広告の『価格』はいくら？」：家は入らない土地だけの値段であることと、「この市（町名）で◯㎡なら、だいたい◯〜◯万円」という相場の幅を表示。まだ決まっていなければ「相場の約◯万円で入れる」をワンタップ。
- 総額を計算の「予算を土地と建物に分ける」：割合の数字の代わりに「🚉場所重視（土地40%）／⚖️ふつう（東海の平均27%）／🏠家重視（18%）」から選ぶ形に。細かい割合は「細かく調整する ▾」から。
- 「広さから総額を出す」の結果も「このうち土地は◯%（東海の平均は約27%）」の言い方に。

## 駅・沿線、入力時のズレ防止（r96）

- 駅・路線データ：国土数値情報「鉄道データ（N02）」（登録不要）から愛知・岐阜周辺の63路線・860駅を `data/stations.json` に集計（ワークフロー「駅・路線データ更新」、毎月1日と手動）。各駅は近くの地価地点から市区町村を判定。
- 沿線で絞り込み：ランキング・地図・通勤などの「📍」に「沿線」（JR中央線、名鉄名古屋本線、地下鉄東山線、あおなみ線、リニモ、愛知環状鉄道など）を追加。予算から探すのステップ4にも「沿線で選ぶ」。
- 土地の登録に「最寄駅」：駅名の候補から選ぶと、乗れる路線を表示。広告の貼り付けでも「◯◯」駅を読み取り。町名で場所がわからないときは最寄駅の位置で通勤を計算。
- 入力時のズレ：入力欄の文字を16pxにしてiPhoneの自動拡大を防ぎ、キーボードを閉じたら画面の位置を元に戻す。
- ランキングで☆の市区町村が常に先頭に固定される設定を、標準でオフに（⚙設定で「★候補を先頭に」をオンにできます）。

## 入力時に画面が動かないように（r97）

- iPhoneでキーボードが出たとき、見えている高さ（visualViewport）にアプリ全体を合わせ、画面全体が上に押し上げられないように。入力欄は必要なときだけ枠の中でスクロールして表示。
- 入力の質問画面は、入力欄を上寄せに配置（キーボードに隠れにくい）。町名・最寄駅の欄は「連絡先を自動入力」などの自動入力を抑制。

## 町名・最寄駅の入力画面（r98）

土地の登録の町名・最寄駅は、ボタンを押すと入力欄が画面の一番上にある専用の画面を開く形に（キーボードが出ても画面が動かない）。文字を打つと候補（町名＝その市の地価地点の町名、最寄駅＝駅名と乗れる路線。選んだ市の駅が先）が絞り込まれ、タップで決定。町名は候補にない名前（番地まで）も「◯◯で決定」で入れられます。
